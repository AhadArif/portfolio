# 🚀 Modern Portfolio Website

A sleek, fully responsive personal portfolio built with **Next.js 15**, **Tailwind CSS**, and **TypeScript**.

![TypeScript](https://img.shields.io/badge/TypeScript-5-blue?style=flat-square&logo=typescript)
![Tailwind CSS](https://img.shields.io/badge/Tailwind-3-38bdf8?style=flat-square&logo=tailwindcss)

## ✨ Features

✅ **Next.js 15** with App Router & Server Components  
✅ **Tailwind CSS** - No external UI libraries  
✅ **TypeScript** - Full type safety  
✅ **Dark/Light Mode** - Persistent theme  
✅ **Fully Responsive** - Mobile-first design  
✅ **SEO Optimized** - Sitemap, robots.txt, metadata  
✅ **Dynamic Content** - All content from `/data` files  
✅ **Accessible** - ARIA labels, semantic HTML  
✅ **Fast** - Optimized for Core Web Vitals  
✅ **Vercel Ready** - One-click deployment

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Open http://localhost:3000
```

## 📁 Project Structure

```
portfolio/
├── app/              # Next.js App Router
├── components/       # React components
├── data/            # Edit your content here! 📝
│   ├── site.ts      # Personal info
│   ├── services.ts  # Your services
│   ├── projects.ts  # Portfolio projects
│   └── experience.ts # Work history
├── public/images/   # Add your images here! 🖼️
└── Configuration files
```

---

## 🎨 Customization

### 1. Update Your Information
Edit files in the [`/data`](data/) directory - this is where all your content lives!

### 2. Replace Images
Add your photos to [`/public/images`](public/images/):
- `hero-image.jpg` (your profile photo)
- `project-1.jpg` through `project-6.jpg` (your project screenshots)

### 3. Customize Theme
Modify colors in [`tailwind.config.ts`](tailwind.config.ts)
